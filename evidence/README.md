## Evidence standard

Use real photographs or screenshots from the project. Do not add generated or stock images as if they were experimental evidence.

Recommended future additions, only when actually captured:

- serial telemetry while the physical node is connected
- backend running with live telemetry
- a measured tilt/calibration setup
- a transient-disturbance vs persistent-change test
- a labelled physical enclosure/node ID

No result should be described as measured unless it was actually measured.
